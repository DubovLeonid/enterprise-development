# Салон красоты — Лабораторная работа

Доменная модель «Салон красоты» с unit-тестами на xUnit.

## Описание

Модель предметной области салона красоты: клиенты, мастера, услуги и записи на услуги.
Реализованы **5 unit-тестов** с использованием **LINQ**:
1. Мастера со стажем ≥ 5 лет.
2. Свободные окошки выбранного мастера.
3. Топ-5 популярных услуг.
4. Повторные записи клиентов за последний месяц.
5. Клиенты, записанные к нескольким мастерам.

## Структура проекта

- **Salon.Domain** — доменные модели и датасид.
  - `Models/` — модели: `Person`, `Client`, `Master`, `Service`, `Appointment`.
  - `Enums/` — перечисления: `Gender`, `ServiceCategory`.
  - `DataSeed.cs` — тестовые данные.
- **Salon.Tests** — unit-тесты на xUnit.

## Технологии

- **.NET 10**
- **C# 13**
- **xUnit** — фреймворк для тестирования.
- **LINQ** — запросы к коллекциям.

## Сборка и запуск тестов

\`\`\`bash
# Сборка
dotnet build Salon.Domain.slnx

# Запуск тестов
dotnet test Salon.Domain.slnx
\`\`\`

**Ожидаемый результат:** `Passed! - Failed: 0, Passed: 5, Skipped: 0, Total: 5`.

## CI

Проект настроен на **GitHub Actions** — при каждом пуше запускаются сборка и тесты. Конфигурация — в `.github/workflows/tests.yml`.
