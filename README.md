# Салон красоты — Лабораторные работы по C# / ASP.NET Core

Данный репозиторий содержит решение лабораторных работ по дисциплине, связанной с разработкой на платформе .NET. 
Проект представляет собой серверное приложение (Web API) для автоматизации работы салона красоты.

## Структура решения

Решение разделено на 3 проекта (чистая архитектура):
* **`Salon.Domain`** — Ядро приложения. Содержит доменные модели (`Client`, `Master`, `Service`, `Appointment`), перечисления (`Gender`, `ServiceCategory`), базовые классы и `DataSeed` (тестовые данные из 1-й лабы).
* **`Salon.Api`** — Веб-слой. Содержит контроллеры, DTO (Data Transfer Objects), настройки Swagger и `InMemoryStorage` (хранилище данных в памяти).
* **`Salon.Tests`** — Проект с юнит-тестами (xUnit) из 1-й лабораторной работы.



## Лабораторная работа 2: Серверное приложение (Web API)

В рамках 2-й лабораторной работы было разработано Web API, которое:
1. Осуществляет **базовые CRUD-операции** с сущностями (Клиенты, Мастера, Услуги, Записи).
2. Предоставляет результаты **аналитических запросов** (раздел «Unit-тесты» из 1-й лабы) в виде JSON-ответов.
3. Использует **DTO (Data Transfer Objects)** для безопасной и чистой передачи данных (скрытие паспортных данных мастеров и т.д.).
4. Документировано с помощью **OpenAPI / Swagger UI**.

### Реализованные аналитические запросы:
* `GET /api/Analytics/experienced-masters` — Вывод мастеров со стажем не менее заданного.
* `GET /api/Analytics/free-slots/{masterId}` — Поиск свободных окошек выбранного мастера.
* `GET /api/Analytics/top-services` — Топ-5 наиболее популярных услуг.
* `GET /api/Analytics/repeat-appointments` — Количество повторных записей клиентов за последний месяц.
* `GET /api/Analytics/loyal-clients` — Клиенты, записанные к нескольким мастерам (сортировка по дате рождения).



## технологии
* **C#** / **.NET 11 (Preview)**
* **ASP.NET Core Web API**
* **In-Memory Storage** (хранение данных в виде коллекций в памяти)
* **LINQ** (для аналитики и фильтрации)
* **OpenAPI** + **Swagger UI** (документация и тестирование)
* **xUnit** (тестирование)


## Как запустить проект
 Склонировать  репозиторий:
  
   git clone <ссылка_репрозиторий >
Откройте файл решения Salon.Domain.slnx в Visual Studio.

В «Обозревателе решений» нажмите правой кнопкой мыши на проект Salon.Api и выберите «Назначить запускаемым проектом» (Set as Startup Project).

Нажмите F5 для запуска сервера.

В браузере перейдите по адресу (порт смотрите в консоли запуска, обычно это https://localhost:7094):
https://localhost:7094/swagger
